# 🌐 HTML Portfolio Challenge

A personal portfolio website built using **only HTML**—no CSS, no JavaScript, and no frameworks.

This project was created as a challenge to focus on writing clean, semantic HTML and understanding the core structure of web pages before adding styling or interactivity.

## 🚀 About the Project

The goal of this challenge was to create a functional portfolio using nothing but HTML. It demonstrates that a website can still be organized, accessible, and informative with just the fundamentals of web development.

## ✨ Features

- Semantic HTML5 structure
- About Me section
- Skills section
- Projects showcase
- Contact information
- Responsive by default using HTML elements
- No external libraries or frameworks

## 🛠️ Built With

- HTML5


## 🎯 Challenge Rules

- ✅ HTML only
- ❌ No CSS
- ❌ No JavaScript
- ❌ No Frameworks
- ❌ No External Libraries

## 📚 What I Learned

- Writing semantic HTML
- Structuring web pages effectively
- Improving accessibility with proper HTML elements
- Building layouts without relying on styling
- Strengthening core frontend fundamentals
